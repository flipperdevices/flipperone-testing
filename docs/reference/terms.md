# Terms

Use these terms consistently in the strategy, tasks, and reports.
Keep tool field names, values, and view names as defined in those tools.

| Term | Definition |
| --- | --- |
| Test candidate | Fixed software versions and artifacts selected for testing |
| Test configuration | Board revision, OS profile, peripherals, settings, and test conditions |
| Acceptance criterion | An observable condition used to accept a function's result |
| Test case | A description of a check's goal, conditions, actions, and expected result |
| Test step | An action or observation within a case |
| Test suite | A group of checks sharing a purpose |
| Test plan | Checks and configurations selected for a task or candidate |
| Test run | Execution of selected checks on a known configuration |
| Baseline | Recorded results of a selected initial scope on a known configuration |
| Initial checks | A small set assessing basic functions and whether further testing is possible |
| Exploratory testing | Investigation with a stated goal and recorded actions, observations, and results |
| Test evidence | Logs, data, measurements, images, and other support for a result |
| Test coverage | Links between requirements or risks and the checks intended to address them |
| Defect severity | The impact of a failure on the user or system |
| Priority | The order in which work is performed |
| Accepted risk | An impact or uncertainty the responsible person accepts for a release |
| Snapshot | A saved state from which a bootable profile can be created |
| Stock snapshot | A preinstalled state used to create profiles |
| Boot Menu | Selection of profile, storage device, and boot settings |

An OS profile defines system content and behavior.
An execution profile selects checks and execution parameters.
Record these separately.
A TestOps Launch contains results from one or more runs
and may include retries and different configurations.

A check result, failure cause, and release decision are separate records.
Accepting risk does not change a failed or missing result into a successful one.

Use product names and technical terms from the
[Developer Portal Glossary](https://docs.flipper.net/one/resources/about-docs/glossary).
